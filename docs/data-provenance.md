# Data provenance

The source video for this work is laparoscopic surgical footage
(`1GP_Endoscopy.MP4`, 30 min, 1920x1080, 29.97 fps).

Redistribution of data derived from it — the point clouds in `results/` and the
meshes in `meshes/` — has been confirmed as permitted.

The raw frames and the source video itself are not included in this repository;
`scripts/` plus the extraction parameters in the README reproduce them from the
source.
